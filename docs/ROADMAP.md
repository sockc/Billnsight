# Roadmap

## V0.1.2 — 首个可用版本

- 微信 XLSX / CSV / ZIP 导入
- 加密 ZIP 解压码
- 微信 / 支付宝识别
- 去重
- 消费/收入/退款/资金流转分离
- 自动分类与商户记忆
- 月度分析
- 小额高频
- 大额支出

## V0.2 — “钱去哪了”增强

- 月份切换优化
- 搜索 / 筛选 / 批量改分类
- 本月 vs 上月
- 每日平均消费
- 工作日 vs 周末
- 单笔 < ¥20 / ¥50 / ¥100 可切换
- 高频商户
- 固定/周期支出识别
- 疑似订阅识别

## V0.3 — 隐私与数据安全

- SQLCipher 或等价数据库加密
- 生物识别 App 锁
- 加密备份 `.bia`
- 本地备份恢复
- 导出通用 CSV

## V0.4 — 智能分析

- 用户自定义分类规则
- 商户别名合并
- 异常消费检测
- “本月多花的钱主要来自哪里”
- 可解释的月度消费摘要

## 暂不做

- 不读取微信/支付宝账号密码
- 不使用无障碍抓取付款页面
- 不 Hook 微信/支付宝
- 不把完整账单上传第三方服务器
