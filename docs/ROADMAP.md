# Roadmap

## V0.1.9 — 信用卡管理、贷款档案、导入预览与规则管理

- 信用卡按卡片汇总、独立的手工还款补录与关联去重
- 按来源、日期与原始交易单号追溯信用卡还款；疑似还款仅人工确认
- 按贷款机构展示累计还款、已拆分本金、利息、手续费及未拆分笔数
- 手动登记原贷款金额和剩余本金，不推测实际债务余额
- XLSX / CSV / ZIP 导入前预览新增、重复、异常、待确认及信用卡还款
- 数据库 V7→V8 非破坏性升级；加密备份覆盖新表
- 集中管理商户分类、商户别名、商品别名，规则更新前预览影响并保护已确认记录
- 最近 7 天、30 天和 12 个月净消费趋势，点击对应日期查看原始流水
- 大文件和 ZIP 解压尺寸限制，避免异常账单消耗手机内存


## V0.1.8 — 贷款还款识别与五界面 UI 2.0

- 微信 XLSX / CSV / ZIP 导入
- 加密 ZIP 解压码
- 微信 / 支付宝来源识别
- 重复导入去重
- 消费 / 收入 / 退款 / 资金流转分离
- 自动分类与商户记忆
- 分类固定颜色
- 微信 / 支付宝来源 Badge 与筛选
- 本月 vs 上月消费变化
- 分类 → 商户二级下钻
- 小额高频 ¥20 / ¥50 / ¥100
- 消费日历
- 疑似固定支出识别
- 大额支出与清理后的商户双列排行卡片
- 持久化商户别名与最近三个月/全部历史排行
- 二维码收付款按方向自动计入个人收支，未知用途仍可待确认
- 个人转账待确认队列
- 红包收支独立统计与红包退回识别
- 可逐笔更改交易性质；兼容旧数据并非破坏性升级
- 全部收入/支出及每条流水支持原地展开
- 商品消费汇总与跨平台原始流水下钻
- 全历史搜索及来源/收支筛选
- AES-256 本地加密备份恢复，兼容数据库 V4
- 贷款还款/贷款到账独立识别
- 本金/利息/手续费按原始金额手动拆分，不对未知金额猜测
- 贷款利息和手续费计入金融费用，贷款本金不计入个人净消费
- 首页四指标财务驾驶舱与逐日数值七日消费趋势
- 流水、分析、发现、我的和底部导航统一视觉设计
- 深浅主题适配、分类图标和来源颜色
- 新增贷款拆分表，SQLite V5→V6 非破坏性迁移
- 信用卡还款单列支出，避免重复计入净消费
- 退款/AA 与原消费关联（部分及跨月），支持撤销
- 收入类型 → 付款人 → 全部交易
- 同一商户商品别名合并，保留原始流水
- 每日收支分组和笔数/金额小计
- 批量处理同方向的待确认交易（至多 100 笔）
- 数据完整性、重复单号及未确认/未匹配退款的只读审计
- 加密备份安全限制和错误密码/损坏包测试

## V0.2 — “钱去哪了”继续增强

- 更丰富的流水高级筛选和金额区间
- 已确认流水按过滤条件批量更正（单独授权及预览）
- 每日平均消费
- 工作日 vs 周末
- 白天 vs 深夜消费
- 疑似订阅识别
- 更复杂的退款匹配建议与多笔收入拆分关联
- 商户别名合并后的金额和退款候选规则进一步校验
- 分类规则命中解释与规则冲突预警
- 贷款还款计划与提醒（录入期数、利率及到期日并由用户确认）

## V0.3 — 隐私与数据安全

- SQLCipher 或等价数据库加密
- 生物识别 App 锁
- 自动备份提醒及恢复兼容性增强
- 导出通用 CSV

## V0.4 — 智能分析

- 异常消费检测
- “本月多花的钱主要来自哪里”
- 可解释的月度消费摘要
- 个人消费与经营支出独立视图

## 暂不做

- 不读取微信 / 支付宝账号密码
- 不使用无障碍抓取付款页面
- 不 Hook 微信 / 支付宝
- 不把完整账单上传第三方服务器
