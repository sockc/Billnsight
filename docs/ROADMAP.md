# Roadmap

## V0.1.5 — 展开式收支分析及加密备份

- 微信 XLSX / CSV / ZIP 导入
- 加密 ZIP 解压码
- 微信 / 支付宝来源识别
- 重复导入去重
- 消费 / 收入 / 退款 / 资金流转分离
- 自动分类与商户记忆
- 分类固定颜色
- 微信 / 支付宝来源 Badge 与筛选
- 本月 vs 上月消费变化
- 分类 → 商户二级下钻
- 小额高频 ¥20 / ¥50 / ¥100
- 消费日历
- 疑似固定支出识别
- 大额支出与高消费商户
- 二维码收付款按方向自动计入个人收支，未知用途仍可待确认
- 个人转账待确认队列
- 红包收支独立统计与红包退回识别
- 可逐笔更改交易性质；兼容旧数据并非破坏性升级
- 全部收入/支出及每条流水支持原地展开
- 商品消费汇总与跨平台原始流水下钻
- 全历史搜索及来源/收支筛选
- AES-256 本地加密备份恢复

## V0.2 — “钱去哪了”继续增强

- 更丰富的流水高级筛选和金额区间
- 批量改分类
- 每日平均消费
- 工作日 vs 周末
- 白天 vs 深夜消费
- 疑似订阅识别
- 红包退回、退款匹配原订单
- AA 分摊与原支付记录关联，净消费按个人实际承担金额统计
- 商户别名合并
- 分类规则管理中心

## V0.3 — 隐私与数据安全

- SQLCipher 或等价数据库加密
- 生物识别 App 锁
- 自动备份提醒及恢复兼容性增强
- 导出通用 CSV

## V0.4 — 智能分析

- 异常消费检测
- “本月多花的钱主要来自哪里”
- 可解释的月度消费摘要
- 个人消费与经营支出独立视图

## 暂不做

- 不读取微信 / 支付宝账号密码
- 不使用无障碍抓取付款页面
- 不 Hook 微信 / 支付宝
- 不把完整账单上传第三方服务器
